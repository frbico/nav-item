# 安全审计与修复记录

审计日期：2026-09-14；部署资源补全与便携模式验证：2026-09-15。审计及本地构建在指定 Debian 虚拟机完成，持续集成在本仓库 GitHub Actions 执行。

## 范围与结论

审阅了应用后端、前端、数据库初始化、原安装脚本、Docker 和工作流，并对认证、上传、输入校验、数据关联及会话进行了动态回归。未在所审阅的应用代码中发现明确的远控、挖矿、凭据外传或混淆执行逻辑；这不等于证明不存在后门，也不覆盖所有历史提交及依赖源码。

原版存在可实际利用的认证绕过等严重漏洞，已在本仓库修复。部署请使用当前 README 和本仓库最新发行资源。

| 问题 | 影响 | 修复与验证 |
| --- | --- | --- |
| 硬编码 JWT 密钥、不校验真实用户 | 任意伪造管理员令牌 | 强制随机部署密钥；限定算法、签发者、受众；校验数据库用户与会话版本；伪造及不存在用户令牌回归 |
| 匿名上传活动内容，无有效大小限制 | 存储型攻击、资源耗尽 | 认证与限流、2 MiB 限制、图片解码/像素限制及 PNG 重编码；HTML/SVG/超大文件回归 |
| 畸形密码参数触发同步异常 | 进程崩溃 | 参数类型校验、异步哈希；畸形对象请求回归 |
| 默认弱密码，无登录限流 | 撞库与暴力破解 | 强密码配置、随机初始化、15 分钟限流窗口；429 回归 |
| 改密和退出不撤销会话 | 被盗令牌持续可用 | 用户会话版本递增；改密与退出后旧令牌拒绝 |
| 外键未启用 | 删除菜单遗留关联数据 | SQLite 外键约束；子菜单与卡片级联删除回归 |
| URL、分页等缺少校验 | 危险链接、异常输入 | 后端输入检查和前端安全 URL；不安全协议及分页回归 |
| 图标地址、子菜单搜索和定位错误 | 展示及交互故障 | 相对图片路径、子菜单搜索及卡片定位修复；前端构建验证 |
| 原共享主机包含旧实现和弱凭据 | 安装后重新引入漏洞 | 从当前源码重建安装包；随机凭据、校验和、拒绝覆盖；独立发布资源 |

## 验证与边界

- 9 项安全回归覆盖原生 SQLite 模式和 Node 内置 SQLite 模式；便携依赖安装排除原生可选模块，使用 WebAssembly 图片处理。
- 前后端 npm audit 在安全修复时为零命中，发布前会再次检查锁定依赖。
- CI 构建 amd64 / arm64，并按各自平台摘要启动验证首页和菜单接口。
- 先前修复镜像的 Trivy 扫描：应用依赖无命中；Debian 系统包仍有暂未提供修复版本的记录（含 High），没有 Critical。扫描结果随数据库更新时间变化，不承诺永远零漏洞。
- 三家共享主机账户未实测，Linux 便携模式测试不能证明具体平台面板与权限兼容。
- 反向代理默认不信任客户端声明的来源 IP，代理后的登录限流可能共用额度。系统仍需正确配置 HTTPS、备份及文件权限。
- 旧数据库中的弱密码、原有第三方导航内容不会被环境变量或升级自动覆盖；管理员应按 README 处理。历史非图片上传已禁止公开提供。
